## 二、第四天共同目标

完成一条同分析 ID 的本地与云端链路，并让 APP 能读取二维码里的内容；两条主线都留下可复查的证据：

1. C 在手机上静态解析用户确认的短链接，返回本次分析的 `Lxx`。这一步不打开浏览器或其他 APP，也不访问网络。
2. 用户明确选择云端分析后，A 通过当次可用的 B 后端地址登录、查看额度、创建任务并轮询同一个 `task_id`。
3. B 的沙箱只访问 D 提供的受控测试站，返回 `C01-C04`；不会提交表单，不记录输入值。
4. A 展示同一 `analysis_id` 的本地和云端证据；D 确认报告只引用本次可用的 `Lxx/Cxx`，结论没有超出证据范围。
5. AI 真实调用不是本日主线。没有用户自愿提供的 Key 时，用规则报告和明确标注的离线 Mock 完成演示；失败时规则报告仍可见。
6. A 能用相机扫描二维码，也能从相册选择含二维码的图片；在手机本地解码并预览内容类型和将触发的行为。D 提供合成的二维码 PNG 样例和预期结果。
7. 二维码只负责提供待检查内容：不自动打开网页/APP、不加入 Wi-Fi、不拨号、不发短信或邮件、不导入联系人、不下载/安装 APK。只有用户确认后，普通 `http/https` 链接才可以进入现有分析流程；原始图片和其他二维码内容不上传。

### 通过标准

- Android 模拟器实际走过“登录 → 额度 → 创建任务 → 轮询 → 报告”，不是只用命令行或旧 fixture 代替。
- 本次任务的 `analysis_id` 在 A、B、C、D 的记录中一致；任务 ID 和证据编号对应得上。
- 报告可展开查看证据来源；仅有本地链接结构时显示“证据不足”，不能称为安全。
- 相机和相册二维码均能解出 D 提供的样例；识别结果先展示类型、脱敏内容和可能行为，再由用户决定是否继续。
- `WIFI:`、`SMSTO:`、`tel:`、`mailto:`、vCard、`intent://`、应用商店/APK 下载等样例均不会被自动执行；非网页 payload 不发给 B。
- 截图与日志不含密码、访问令牌、真实个人信息或 API Key；B 的云端证据不含表单输入值。
- 汇总 Flutter、Android/Kotlin、后端和报告契约的实际检查结果；未跑的项目写“未验证”，不推测通过。

## 七、依赖关系与并行顺序

工作时间不固定，以下是交接顺序，不是必须同一时间在线：

| 先交付什么 | 会卡住谁 | 卡点 | 等待时可先做的事 |
|---|---|---|---|
| B 给出仍有效的 API 地址、测试账号方式并启动 worker | A | APP 无法创建真实云任务 | A 构建、测试错误提示和离线演示；B 跑回归并生成可审计快照 |
| D 提供受控测试站入口和预期页面行为 | B、A | B 无法采集指定短链；A 无固定输入 | B 用已有受控站跑 smoke；A/C 做本地解析和离线页面验收 |
| D 提供静态二维码 PNG、payload 清单和预期结果 | A、C | A 缺真实图片验收扫码/相册流程；C 缺二维码 payload 边界输入 | A 先用 D 交接的原始虚构字符串做分类/预览；C 先覆盖 URL、Intent 和不支持输入 |
| B 给 D 当前有效的受控测试站地址 | D、A | D 无法生成可用于本次云端主案例的动态二维码；A 无法从扫码直接进入真实采集 | D 先生成其他类型的静态样例和本地脚本；A 先完成 QR 解码与本地预览 |
| A 完成相机/相册解码与预览 | C、D | C 无法核对解码字符串是否正确交给本地分析；D 无法在 APP 验收其样例 | C 先用固定 payload 验证解析边界；D 先通过脚本检查 PNG 与 manifest |
| C 提供 A 本次 `analysis_id` 的本地 JSON | A、D | APP 无法展示本次 `Lxx`；D 无法审本地报告引用 | A 使用标记清楚的 fixture 测页面；D 跑报告守卫和历史测试 |
| A 在模拟器创建本次云任务并展示报告 | D、最终演示 | 无法证明手机端页面接上真实云端数据 | B 用 API/命令行证明后端；C 完成本地调用；D 先审脱敏 JSON |
| D 完成本次报告审计 | 最终演示 | 无法确认用户结论和证据对应 | A 保留规则报告，B/C 继续回归，不把未审报告当最终结论 |

建议起步时并行：B 启动云服务；C 跑本地模块回归；D 先生成静态 QR 样例与 manifest，再等 B 的临时站地址生成现场二维码；A 接入本地扫码/相册识别并构建 APK。B 给出可用地址后，A 扫现场短链并跑手机云端任务，C 提交同 ID 的本地结果，D 最后审报告。
