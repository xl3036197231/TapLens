## 二、A：补齐手机端验收与错误处理

### 要做的事

1. 保存学校模型客户端将发送的**完整脱敏 JSON 请求体**，只保留本次分析需要的五段字段；不得保存 Authorization、JWT、密码或 Key。校验所有 URL、ID、字段类型和长度。
2. 将同一 JSON 请求体 POST 到学校模型接口，但不带 JWT。合法请求体应返回 `401 AUTH_TOKEN_MISSING`，且不会调用 Provider。若仍返回 `422`，保存 HTTP 状态和脱敏响应中的 `error.code`、`error.details.fields`；若 FastAPI 返回标准 `detail` 数组，也要保留其中的 `loc`、`msg`、`type`。按具体字段错误修正请求体，再重复无 JWT 预检，直到得到预期 401。
3. 与 B/C 确认模拟器可以访问后端后，从模拟器分别检查 `/healthz` 和 `/api/v1/health`。主机能访问不等于模拟器能访问；若失败，先解决路由、端口或 Android 明文 HTTP 配置问题，不要带 JWT 或触发模型请求。
4. 只有无 JWT 请求已返回预期 401、模拟器健康检查通过、B 确认服务端状态正常后，才携带测试账号 JWT 对正式脱敏请求执行**一次**模型推理，并保存完整脱敏报告 JSON、APP 截图、模型名和 Token 用量。若请求超时或响应丢失，先让 B 检查 Provider 调用记录，确认未推理后再决定是否重试。
5. 用测试替身覆盖“查询已有任务”流程，证明填写 `task_id` 后只执行健康检查和只读 GET，不会调用创建任务的 POST；覆盖后端不可达、过期和未找到等情况。B 确认任务仍可读且网络已通时，才在模拟器上做真实只读查询。
6. 回归本地预检、学校模型错误提示和规则报告回退；整理脱敏截图与操作记录，明确标记“真实服务结果”或“测试替身结果”。

### 交付物与完成标准

- 脱敏请求 JSON、离线字段检查结果、无 JWT 预检的状态码/错误字段、修正后的回归结果及 Dart 静态分析结果。
- 查询已有任务的测试记录，能证明走 GET 路径、没有创建任务请求。
- 模拟器 `/healthz` 与 `/api/v1/health` 检查结果。正式模型推理必须发生在以上预检均通过之后。
- 若正式模型推理成功：交付完整脱敏报告、APP 展示截图和真实 Token 用量；若失败，提供服务端是否实际调用 Provider 的核查结果，不能仅凭客户端超时推断。
- 如真实只读查询成功：提供同一任务 ID 的 APP 页面截图、最终状态和操作记录；若服务端已过期/不可达，记录实际错误，不伪造成功截图。
- 若没有完整真实 AI 响应，继续标记 AI 报告验收为 BLOCKED；规则报告回退可单独演示。

2. 定位模拟器到 `39.107.253.138:80` 被拒绝的原因。分别检查服务监听、云端入口/安全组和模拟器访问路径，并提供可由模拟器实际验证的地址或明确的不可达结论。
3. 与 A 核对不带 JWT 的接口预检：合法请求体应在 Provider 前返回 401；若响应为 422，协助根据 FastAPI `loc/msg/type` 或 `error.details.fields` 找到具体字段。核查请求 ID/后端日志，证明该预检没有调用 Provider。

|---|---|---|---|
| B 确认正式任务是否仍可读、排查模拟器到 ECS 的连接 | A、C | A 的真实只读查询；C 的设备联网回归 | A 做只读路径 Mock 测试和错误提示；C 做本地 MethodChannel/Schema 回归；B 查服务监听和日志 |

| A 交付最新 APP 证据、C 交付设备复测记录 | D | D 的最终设备展示核对 | D 先审 JSON、Schema、ID、URL、证据引用和脱敏情况，并把未完成项标为 BLOCKED |
| D 输出最终审计结论 | 全组 | Day 6 联合验收能否关闭 | 对明确的 FAIL 按责任人修复；BLOCKED 项不通过补造样例或重复收费调用来消除 |

建议按此顺序推进：

1. **A/B 并行完成零模型消耗的请求体预检**：同一脱敏 JSON、不带 JWT；预期 401。若 422，先保存字段错误并修正，禁止进入正式推理。
2. **B/C 并行确认模拟器健康检查可达**：在模拟器实际访问 `/healthz` 和 `/api/v1/health`，修复网络路径后再继续。
3. **A 执行一次正式模型推理**：前两步都通过后带测试 JWT 调用；B 同时只读核对 Provider 调用记录。若响应未知，先查日志，不盲目重试。
4. **A/C 做已有任务只读查询回归，D 做最终整包审计**：任务若已过期则停止真实查询，使用固定证据做离线回归并标注限制。

- A 的 HTTP 422 属于 FastAPI 校验失败，没有调用模型或消耗 Token；不把它计作正式推理。完成无 JWT 401 预检和模拟器健康检查后，A 按既有验收授权只做一次正式推理。B 的 5322-token 成功调用是另一请求，不与 A 的 422 混算。
