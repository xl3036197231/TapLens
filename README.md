# TapLens（触镜）

触镜 TapLens 是一款面向移动二维码与链接场景的 AI 交互承诺验证应用。

## 核心能力

1. **多入口采集**：支持扫描海报二维码、导入聊天截图、粘贴链接。
2. **端侧隐私保护**：在设备端提取宣传内容，并自动遮盖手机号、学号、令牌等敏感信息。
3. **真实行为还原**：
   - 通过隔离网页沙箱还原页面跳转、表单行为与外部调用。
   - 通过 Deep Link 解析器识别外部 App 唤起目标与参数传递。
4. **承诺对比解释**：AI 对比“页面宣传承诺”与“实际准备执行的操作”，输出结构化解释报告。
5. **证据约束与降级**：
   - 报告包含宣传承诺、真实行为、关键差异、技术证据。
   - 云端模型不可用时，自动降级为本地模板报告，保障可用性。

## 示例场景

- 宣称“领取校园助学金”，实际却跳转贷款申请并索取身份证号。
- 宣称“打开官方校园 App”，Deep Link 实际指向其他包名。

TapLens 帮助普通用户在执行移动端操作前，基于证据做出更清楚的判断。
